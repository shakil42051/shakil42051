<details>
<summary><b>Bonus level: can you beat this boss without leaving the README?</b></summary>

**Mission:** Find the one-line fix that makes this loop read only valid elements.

```c
int values[] = {4, 8, 15};
int total = 0;
for (int i = 0; i <= 3; i++) {
    total += values[i];
}
```

<details>
<summary>Choice A · Set total to 1</summary>

The loop still reaches `values[3]`, outside a three-element array. The starting total does not fix the boundary. Try again.

</details>

<details>
<summary>Choice B · Change i &lt;= 3 to i &lt; 3</summary>

**BOSS DEFEATED.** The valid indices are `0`, `1`, and `2`. With `i < 3`, the sum is **27** and every read stays inside the array.

Achievement unlocked: **Boundary Guardian**. Your reward is one fewer mysterious bug.

</details>

<details>
<summary>Choice C · Change i++ to ++i</summary>

Both increment forms advance this loop by one. The condition still allows index `3`. Try again.

</details>
